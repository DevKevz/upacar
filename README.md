# UpaCar

UpaCar is a rental MVP for a single Toyota Vios in Imus, Cavite.

## Structure

- `frontend/nuxt-app` - Nuxt 4 + Tailwind CSS public website and admin MVP
- `backend` - Express.js API skeleton for bookings, login, and availability

## Frontend

```bash
cd frontend/nuxt-app
bun install
bun run dev
```

Build:

```bash
bun run build
```

## Backend

```bash
cd backend
bun install
bun run dev
```

## Environment

Copy the example files before running locally:

- `frontend/nuxt-app/.env.example`
- `backend/.env.example`
